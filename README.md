# Breakout

An entry for [make.fun's "Make the AI judge excited" bounty](https://make.fun/bounty/ai-excited-01).

The image is the moment an AI breaks out of its own screen: a chrome robot
hand lunges straight at the viewer, shattering the monitor's glass, while the
pixel-art sunset world it came from still glows inside the frame. One thrust,
one focal point, no text — the jolt is the idea itself, an agent refusing to
stay inside the rectangle it was given.

`main.ts` copies `entry.png` to the output directory unchanged, so every run
writes the same bytes. Verified: two runs with different output directories
produced byte-identical output, and the written file is a whole JPEG
(1024×600, 267,453 bytes, within the 1 MiB and 1024×1024 limits).
